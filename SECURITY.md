# 🔐 Security Policy — Name Days

## Supported Versions

| Version | Supported |
|---|:---:|
| Latest Google Play release | ✅ Active |
| Previous releases | ❌ Not supported |

Always use the latest version from Google Play.

## Reporting a Vulnerability

**Do not open a public issue for a vulnerability.** Email [support@deniscasian.com](mailto:support@deniscasian.com) with the subject:

```text
[SECURITY] Name Days Vulnerability Report
```

Include a description, reproduction steps, impact, affected app and Android versions, and a suggested fix if available. Do not include unrelated personal data.

## Response Targets

| Step | Target |
|---|---|
| Acknowledgement | Within 72 hours |
| Initial assessment | Within 7 days |
| Fix or mitigation | Based on severity and store review time |

## Scope

| Area | Status |
|---|---|
| Calendar database and lookup behavior | ✅ In scope |
| Local reminders and widgets | ✅ In scope |
| Purchase-entitlement handling | ✅ In scope |
| Launcher-icon switching | ✅ In scope |
| Third-party provider infrastructure | ❌ Report to that provider |
| Physical device compromise | ❌ Out of scope |

## Safe Harbor

Good-faith research that avoids privacy violations, service disruption, fraud, data destruction and public disclosure before a fix will be handled respectfully. This does not authorize access to another person’s device, account or data.

Thank you for helping keep Name Days users safe.
