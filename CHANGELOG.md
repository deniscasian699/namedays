# 📋 Name Days — Changelog

## Unreleased — Next release

### Added

- Google AdMob adaptive banner, native, interstitial and app-open advertisements.
- UMP consent checks and advertising privacy options in Settings where required.
- Ad removal for One-Time Supporter and active Monthly Supporter; Premium Lifetime keeps ads.
- Persistent navigation counter and a startup guard for interstitials.
- Centralized ad caching, request cooldowns and retry backoff. Interstitials require six qualifying user actions, are never shown automatically at launch, and have a 120-second cooldown after dismissal; failed loads are retried no sooner than 120 seconds later.
- Home-screen widget previews for older and newer Android launchers.
- Widget customization in Settings: colors, name text size and country visibility.
- Updated bundled name-day calendars.

### Documentation

- Updated Privacy Policy, Terms of Use and app presentation for advertising and the rdcapps.com domains.
- Public documentation and issue templates modeled on the developer's RealMeteo repository.
